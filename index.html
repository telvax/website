telvax

If it compiles, it fits.

Telvax reads like Python and checks like a compiled language. The shape of a tensor, the columns of a table and the body of an HTTP request are types, so the mistakes that usually show up in production show up in the editor.

01 / the problem

The shape bug you find an hour into a run is a compile error here.

A data and ML stack is usually three languages held together with glue: one for the model, one for the service around it, and SQL in strings between them. Each seam is checked only when the data reaches it.

Telvax puts the seams in the type system. A matrix product of mismatched shapes does not compile. A misspelled column does not compile. A request body that does not match its type never reaches your function.

  • Shape is type. Tensor[f32, 2, 3] carries its shape through every call.
  • No glue code. One file holds the types, the pipeline and the route.
  • Errors are values. Result, Option and ?, with no exceptions to forget.

Reported at the call, before anything runs. Sizes known only at run time use symbolic dimensions: Tensor[f32, N, 3].

02 / solutions

Four jobs, one language.

Each of these is a program in the repository that you can run after the install.

Data analysis

Tables with typed columns

Table[Row] is an Arrow table whose columns are the fields of Row. It reads CSV, Parquet and Arrow and runs SQL. sales.prise is a compile error, not a failure halfway through a report.

type Sale:
    region: Text
    units: Int
    price: Float

fn main():
    let sales: Table[Sale] = read_csv("sales.csv")
    print(f"mean price: {sales.price.mean()}")

Machine learning

Models whose shapes are checked

Every layer states the shape it takes and the shape it returns. The checker follows them through the whole model, so a layer that does not fit the next one is caught when you save the file.

fn layer1(x: Tensor[f32, 2, 3], w: Tensor[f32, 3, 4]) -> Tensor[f32, 2, 4]:
    x.matmul(w).relu()

fn layer2(h: Tensor[f32, 2, 4], w: Tensor[f32, 4, 2]) -> Tensor[f32, 2, 2]:
    h.matmul(w).softmax()

AI serving

A function becomes an HTTP route

@endpoint turns a function into a JSON route. The parameter type is the request body and is validated for you; an Err becomes the right status code. telvax build --serve makes one binary and a Dockerfile.

@endpoint(POST, "/v1/sentiment")
fn sentiment(input: Input) -> Result[Output, Status]:
    if input.text.is_empty():
        return Err(Status.BadRequest("empty text"))
    let score = score_of(input.text)
    Ok(Output(label: label_of(score), score: score))

Retrieval and LLMs

A RAG service in one file

Embeddings, vector search and an LLM call, composed with the pipeline operator. The embedding size is in the type, so the model and the index cannot disagree about it.

fn embed(text: Text) -> Tensor[f32, 768]:
    text
        |> std.text.clean_whitespace()
        |> std.text.truncate(512)
        |> embedder.embed()

04 / tools

05 / install

Running in a minute.

Telvax is a command-line tool. The script installs telvax and tvpm in ~/.telvax/bin.

Early alpha

Good for trying the language and giving feedback. Expect bugs and breaking changes in the library and the tools; the syntax of edition 2026 is frozen. What works, and how it was verified, is listed in the status document.
