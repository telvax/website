# Telvax website

The public site for Telvax: landing page, links to the guide, downloads and the playground.

## Status

Only the landing page is planned here and nothing is built yet. The documentation site already exists:
it is `site/` in [telvax/telvax](https://github.com/telvax/telvax), published at <https://telvax.github.io/telvax/>.
The playground (WebAssembly) is `playground/` there too and stays there while it is built together with the compiler.
